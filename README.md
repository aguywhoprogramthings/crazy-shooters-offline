# Crazy Shooters Offline

The playable package and launch instructions are in [`crazy_shooters_offline/`](crazy_shooters_offline/README.md).

Download the `crazy-shooters-offline` artifact from a successful **Test and
package** run for the desired branch under GitHub Actions, extract the included
game ZIP into a new folder, and follow the launch instructions. Look for
**Optimized v3** in the bottom-left of the game to confirm the optimized copy is
running. The workflow tests and packages the checked-in Unity WebGL build; it
does not rebuild the unavailable Unity source project.
