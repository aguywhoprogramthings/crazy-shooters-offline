# Crazy Shooters Offline

The playable package and launch instructions are in [`crazy_shooters_offline/`](crazy_shooters_offline/README.md).

Download the `crazy-shooters-offline` artifact from a successful **Test and
package** run under GitHub Actions, extract the included game ZIP, and follow
the launch instructions. The workflow tests and packages the checked-in Unity
WebGL build; it does not rebuild the unavailable Unity source project.
